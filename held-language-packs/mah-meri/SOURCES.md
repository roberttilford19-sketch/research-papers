# Sources — Mah Meri (mvq)

Pointers only. This file cites the published sources and catalogues behind the Mah Meri held-language pack; it reproduces none of their text. Anything quoted in the pack's documents is quoted there, briefly, with its source named in the same breath.

## The published record of the language

- Kruspe, Nicole. *A Dictionary of Mah Meri as Spoken at Bukit Bangkong.* Oceanic Linguistics Special Publication 36. University of Hawai'i Press, 2010. ~4,000 entries, Mah Meri–English–Malay. Paper ISBN 978-0-8248-3493-7. Publisher's page: https://uhpress.hawaii.edu/title/a-dictionary-of-mah-meri-as-spoken-at-bukit-bangkong/ — the lane's named base. Access state: archive.org holds a controlled-lending copy only ("Access-restricted-item: true"): https://archive.org/details/dictionaryofmahm00nico ; the eBook is behind JSTOR Books / Project MUSE / De Gruyter institutional authentication. Class: LIBRARY-ONLY.
- Kruspe, Nicole — Mah Meri documentation materials, ELAR (SOAS). A corpus lead for a follow-up pass, not the dictionary.
- SEAlang — lists a "Betise' (Mah Meri, Besisi)" lexicon; carries no Kruspe dictionary text: http://sealang.net/monkhmer/database/byLanguage.htm
- Kruspe, Nicole. *A Grammar of Semelai.* Cambridge University Press, 2004. Cited here only to keep the record straight: Kruspe's published dictionary is Mah Meri; no standalone Kruspe Semelai dictionary exists (the Semelai base is that grammar's vocabulary appendix and its SEAlang extraction).

## The catalogues of record

- Ethnologue — entry for Mah Meri [mvq]: https://www.ethnologue.com/language/mvq (the Malaysia wave records carry the lane under the code mhe).
- Glottolog — entry for Mah Meri at https://glottolog.org
- OLAC (Open Language Archives Community) — Mah Meri records at http://www.language-archives.org/language/mvq
- RWAAI (Lund) and ELAR (SOAS) — the Aslian documentation archives of record for Kruspe's field materials.
- Dewan Bahasa dan Pustaka — no DBP Mah Meri dictionary was found (checked 2026-11-17). No Mah Meri scripture portion exists in any catalogue searched.
