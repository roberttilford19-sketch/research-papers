# Mah Meri — A Held-Language Research Pack

This pack gathers everything assembled at this desk about the Mah Meri language in the course of Robert Tilford's Quran translation project. It is a research pack, not a translation. No Mah Meri Quran translation exists, and none is claimed here or anywhere in this project. What follows is the record of an honest search: what was looked for, what was found, and the thing that was not found, named plainly so that no one mistakes this shelf for a finished work.

## The language

Mah Meri (ISO 639-3: mvq) is a Southern Aslian language — Aslian being the Peninsula branch of Austroasiatic, a different family from the Austronesian languages that fill most of this project. It is an Orang Asli language of the Selangor coast in Peninsular Malaysia, documented in depth as spoken at Bukit Bangkong. (The Malaysia wave records carry this lane under the code mhe; the pack is filed under mvq, the catalogue code for Mah Meri.) Mah Meri is not Malayic, and no Malayic base can stand in for it: a draft on a Malay base under a Mah Meri label would mislabel the book, which this house does not do.

## The base, and why the lane is held

Mah Meri's case is the inverse of most held lanes: the dictionary exists, and it is a good one. Nicole Kruspe's *A Dictionary of Mah Meri as Spoken at Bukit Bangkong* (Oceanic Linguistics Special Publication 36, University of Hawai'i Press, 2010) holds some 4,000 entries, Mah Meri–English–Malay — exactly the base a build would want. What the desk does not have is lawful access to its text. No open full copy was found anywhere: archive.org holds the book as a controlled-lending item only, to be borrowed with an account rather than downloaded; the eBook sits behind JSTOR Books, Project MUSE, and De Gruyter institutional authentication; the print volume is in print from the press. SEAlang lists a "Betise' (Mah Meri, Besisi)" lexicon but carries no Kruspe dictionary text, and the Endangered Languages Archive holds Kruspe's Mah Meri documentation materials — a corpus lead for a follow-up pass, not the dictionary. No Dewan Bahasa dan Pustaka Mah Meri dictionary was found, and no Mah Meri God-term is attested in any source the desk could reach. A full dictionary behind a library door is a base the lane can name but cannot build on. The lane is therefore HELD.

## The open seat

The pack's status can be stated in one line, and it is stated here verbatim so that it travels with the pack wherever the pack goes:

**Open seat: "God-term unverified — community usage not yet located."**

The base carries a second, named condition beside it: the desk's Mah Meri base is LIBRARY-ONLY — a published dictionary of record, held in physical and institutionally gated copies, with no lawful open text.

## The one road not taken

The road here is plainly a library road: Kruspe's dictionary read through a research library's holdings or its controlled-lending copy, and her ELAR documentation collection examined as a corpus. Access decisions of that kind are taken deliberately at this desk, and none has been taken for this lane. Until one is, this pack is the lane's honest resting place: everything known, gathered in one place, with the gap named rather than papered over.
