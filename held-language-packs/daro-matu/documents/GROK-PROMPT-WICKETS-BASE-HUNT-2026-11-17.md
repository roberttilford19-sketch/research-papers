RESEARCH TASK — lexical bases for seven Malaysian languages (Sarawak, Sabah, and Peninsular Malaysia)

You are helping research a translation project. We translate into small Malaysian languages, and each language needs a real lexical base — a dictionary, wordlist, or grammar with vocabulary — in digital form we can lawfully use. Seven languages are stuck because we could not find a usable base. Your job is to hunt for one for each. Search only — do not contact anyone, and do not buy anything; if a source is for sale, report it as purchase-only with its publisher and price if shown.

THE SEVEN, IN PRIORITY ORDER:
1. **Belait** (Brunei / Sarawak border) — closest relative of Kiput; we know of library holdings only, nothing digital.
2. **Jah Hut** (Peninsular Malaysia, ISO: jah) — a 1976 study exists (Diffloth); is there anything fuller, or a digitized copy of anything?
3. **Semelai** (Peninsular Malaysia, ISO: sza) — any dictionary or substantial wordlist?
4. **Daro-Matu** (Sarawak Melanau group, ISO: dro) — any dictionary or wordlist?
5. **Molbog** (Sabah / Palawan border, ISO: pwm) — partial materials exist; anything fuller?
6. **Uma' Lasan** (Sarawak) — we found no dedicated lexical resource listed anywhere; confirm or overturn.
7. **Jangkang** (West Kalimantan / Sarawak border) — we found no lexical resource listed anywhere; confirm or overturn.

FOR EACH LANGUAGE, FIND:
- Any digitized dictionary, wordlist, glossary, or grammar-with-vocabulary: title, author, year, publisher or repository, and a URL or catalogue number. Check especially: Malaysian university repositories (Universiti Malaya, UKM, UNIMAS, USM, UMS), Dewan Bahasa dan Pustaka, SIL International, PARADISEC, Kaipuleohone, archive.org, SEAlang, Glottolog's bibliography, WorldCat.
- Any Scripture portions, hymnals, catechisms, or religious vocabulary lists — and if one exists, the word used for God, quoted verbatim.
- If the only copies are physical library holdings, name the library and the catalogue record.

RETURN FORMAT — per language, give:
- Each source found, with a verbatim quote of the catalogue entry or a sample entry line
- The access class, one label: IN HAND DIGITALLY / PARTIAL / LIBRARY-ONLY / PURCHASE-ONLY / NOT FOUND
- The catalogues and sites you searched for that language, including the empty ones

RULES:
- Never guess or invent a source, a title, or a word. If it is not in a source you can cite, it does not count.
- Report negative results in full. A documented "not found" after a real search is a useful answer — it closes the question honestly.
- Keep the seven languages separate. A resource for one language is never evidence for another.
